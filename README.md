# Student Hub 
Student Hub is a platform for college students to discover friends, study buddies, project collaborators, and student projects. 
## Stack Frontend: 
- React 
- TypeScript 
- Vite 

Backend: 
- Ruby on Rails API 

Database: 
- PostgreSQL 

Infrastructure: 
- Docker 

## Development 

Start PostgreSQL: docker compose up -d 

Start Rails: cd student-hub-backend bin/rails server 

Start React: cd student-hub-frontend npm run dev
